## Overview

MeldaProduction MNoiseGenerator produces white, pink, brown, and custom-shaped noise alongside sinusoidal tones for test signal generation, room acoustics measurement, and texture creation.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **MeldaProduction MNoiseGenerator** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Noise Types** | White, pink, brown, and user-shaped noise spectrum generation |
| **Tone Generator** | Sine, square, and other waveform test tone generation |
| **Sweep Mode** | Automated frequency sweep for room acoustics measurement |
| **Free Plugin** | Fully free from MeldaProduction for test and creative use |
